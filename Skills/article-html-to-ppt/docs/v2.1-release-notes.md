# PPTSmith 2.1.2 Release Notes

PPTSmith 2.1.2 is a visual-narrative, delivery-reliability, and security-hardening release.

## Highlights

- Adds task routing, Page Design Intent, Visual Planner, Deck Rhythm Gate, and
  bounded visual revision requests.
- Binds declared semantic components to verified Renderer capabilities and
  fails closed when a required Renderer is unavailable.
- Adds editable heat matrix, layered architecture, drill-down stair, and phase
  roadmap renderers.
- Strengthens Standard production QA for severe overflow, text/background
  contrast, arrow and chevron text safety, semantic footnotes, stale render
  evidence, and editable-content coverage.
- Improves generic consulting layouts with presentation-scale covers,
  full-canvas single charts and tables, metric walls, source footers, sparse
  card expansion, compact low-row tables, and vertically balanced processes.
- Passes macOS PowerPoint render paths through `osascript` arguments instead
  of interpolating them into AppleScript source.
- Restricts fixture regeneration cleanup to its real non-symlink
  `tests/fixtures/qa` directory.
- Reports only required-font availability instead of a broad installed-font
  inventory.
- Loads fixture safety helpers through a normal static import so the public
  package does not contain dynamic module execution.

## Verified scope

- Standard production is accepted on macOS with LibreOffice 26.2.4.2.
- Fresh public-repository verification: 223 unit/schema tests and 26 integration tests passed.
- McKinsey regression: 10/10 slides rendered with zero QA issues.
- Latin America report: 12/12 slides rendered with editable core ratio 1.0.
- Future of Jobs Hero Showcase: 12/12 slides rendered, zero QA issues, zero
  media files, zero whole-slide rasterization, and internal rubric 17/18.

## Honest boundary

This release verifies a clean, editable consulting baseline for Standard
production. Premium quality remains run-specific and requires real rendering,
readback, zero-error QA, rubric scoring, human visual review, and disclosed
fallbacks. The Hero Showcase represents a high-fidelity native upper-bound
case; it is not evidence that every source reaches the same result in one
automatic pass.

## Compatibility

- Installed OpenClaw route remains `article-html-to-ppt`.
- `MeowClaw PPTSmith` is the English alias and
  `MeowClaw 夜猫 PPT 工坊` is the public display name.
- Existing v2.0 contracts remain supported; new v2.1 contracts are additive.
