# PPT Smith v3.0.1 发布说明：公开 PMO 运行时

v3.0.1 是一次公开发行边界修正。它保留 v3.0.0 的 Path A 高定代码路径、Path B 可验证 IR / Pipeline 路径、八条专业路线、视觉叙事与来源绑定的证据质量门禁；新增明确的公开 PMO 运行时分发规则。

## 公开内容

以下 PMO 内容随公开 Skill 发行包分发：

- 页面适配器、组件、决策支持、路由和质量规则；
- PMO 输入与组件 schemas、样式合同、taxonomy；
- 构建和验证脚本、示例、状态说明与用户文档；
- 根 Skill 的 PMO 自动路由说明。

目录 `private-pmo-pack/` 因兼容性保留原名称；它在 v3.0.1 中代表公开 PMO 运行时，而非私有或禁止发布的资产。

## 不随注册表发行的内容

为避免把本地实现和测试副产物当作产品内容，ClawHub 与 SkillHub 包都排除：

- `tests/` 与 `private-pmo-pack/tests/`；
- `private-pmo-pack/output/` 中的生成 PPTX 和分析结果；
- `private-pmo-pack/qa/` 中的 PDF、渲染图、QA 报告和日志；
- `private-pmo-pack/visual-system-comparison/`、缓存、`node_modules`、`.verification/` 与 Python 缓存。

GitHub 公开 PMO 源码和说明；ClawHub 与 SkillHub 从同一份运行时源码打包，并在上传时排除上述本地测试与生成物。历史开发证据若仍在仓库中，不构成注册表发行包的一部分。

## 交付边界不变

公开 PMO 运行时不代表所有项目材料或所有 Office 环境自动达到最终交付质量。PPT Smith 仍区分 Created、Rendered、Read back、Verified 与 Final；Premium 交付仍需要目标环境真实渲染、回读、零错误 QA、评分与人工视觉复核。
